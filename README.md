# tyberkyleznik

Обычная игра с друзьями: **GitHub Pages + существующий Supabase**, без отдельного
сервера и SSH. [Текущее состояние и минимальный план публикации](docs/public-playtest.md).
Сайт: https://pepen40.github.io/tyberkyleznik/ . Доступность страницы не подтверждает
исправность входа, backend и экономики; проверенные изменения audit-ветки ещё
нельзя считать опубликованными.

Каталог `closed-test/` сохранён как необязательный изолированный стенд и история
CI-проверок. Его Linux/SSH-инструкции не нужны для обычного публичного сайта.
